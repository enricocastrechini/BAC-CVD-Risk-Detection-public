# Contributing

Thank you for helping improve this research repository. Contributions should preserve the scientific meaning of the BAC classification task and make the three pipelines easier to reproduce.

## Before opening a pull request

- Explain the problem and the smallest change that addresses it.
- Keep private mammography data, patient identifiers, credentials, checkpoints, and generated results out of Git.
- Add or update a focused test, smoke check, or reproducible command when behavior changes.
- Run the narrowest relevant validation and report the command, environment, and limitations.
- Update the relevant README when setup, configuration, output paths, or assumptions change.

## Pull requests

Use a descriptive title and include:

- what changed and why;
- which pipeline is affected;
- validation performed;
- data, GPU, dependency, or external-service requirements;
- whether any figures are illustrative or generated from a verified experiment.

Please do not include patient images or sensitive metadata in issues, pull requests, logs, screenshots, or example fixtures.
